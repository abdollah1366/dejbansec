دژبان‌سک — انتقال درخواست پروژه به Live Chat

این افزونه برای سایت دژبان‌سک ساخته شده است.

کار:
1) منوی «درخواست‌های پروژه» مربوط به dsu_lead را از مدیریت مخفی می‌کند؛ داده‌های قدیمی حذف نمی‌شوند.
2) فرم «شروع همکاری» افزونه دژبان‌سک Ultimate را به جدول‌های Live Chat Pro متصل می‌کند.
3) درخواست مشتری به‌عنوان اولین پیام یک گفتگوی Live Chat ذخیره می‌شود.
4) نام، شماره/ایمیل، نوع پروژه و شرح درخواست همراه پرونده مشتری ذخیره می‌شود.
5) اگر Live Chat Pro و n8n تنظیم شده باشند، همان مسیر اعلان n8n استفاده می‌شود.
6) شناسه‌های localStorage چت به فرم متصل می‌شوند تا درخواست و چت عادی همان مرورگر در یک پرونده قرار بگیرند.

پیش‌نیاز:
- دژبان‌سک Ultimate فعال
- دژبان‌سک Live Chat Pro 2.1 فعال

نصب:
فایل ZIP را در wp-content/plugins آپلود و Extract کنید، سپس افزونه «دژبان‌سک — انتقال درخواست پروژه به Live Chat» را فعال کنید.
