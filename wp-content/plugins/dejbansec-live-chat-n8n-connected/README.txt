دژبان‌سک Live Chat — نسخه 1.1.0 — اتصال n8n

نسخه اصلاح‌شده خطای فعال‌سازی PHP است.

نصب:
1) اگر نسخه قبلی «دژبان‌سک Live Chat» در افزونه‌ها وجود دارد، آن را فعال نکنید.
2) پوشه قبلی dejbansec-live-chat را از wp-content/plugins حذف/rename کنید.
3) این ZIP را در wp-content/plugins آپلود و Extract کنید.
4) در وردپرس > افزونه‌ها، «دژبان‌سک Live Chat» را فعال کنید.
5) Webhook n8n را فعلاً خالی بگذارید.

اگر وردپرس همچنان خطای فعال‌سازی داد، متن دقیق خطا یا اسکرین‌شات آن را ارسال کنید.


تنظیم n8n:
Webhook پیش‌فرض نسخه 1.1.0 روی آدرس تستی n8n کاربر تنظیم شده است.
قبل از ارسال پیام، در n8n روی «Listen for Test Event» بزنید.
هر پیام Live Chat با POST و JSON به Webhook ارسال می‌شود.
برای محیط Production، پس از تست باید آدرس /webhook-test/ با /webhook/ جایگزین شود.
